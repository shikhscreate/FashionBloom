# FashionBloom

FashionBloom is a frontend-only women's fashion e-commerce website prototype built using HTML, CSS, and JavaScript.

## Features

- Product listings with categories
- Search functionality
- Add to cart
- Quantity control
- Dynamic cart total calculation
- Checkout and billing UI
- Responsive and user-friendly design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- DOM Manipulation

## Project

This project was developed as part of my InternPe Web Development Internship to practice frontend development, UI design, and JavaScript-based user interactions.
